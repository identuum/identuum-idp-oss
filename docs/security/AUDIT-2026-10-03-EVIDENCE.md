# Evidence that the 2026-10-03 audit's fixes hold (OSS-AUDIT-CLOSE-1)

Audit: the workspace wiki's `security/oss-security-audit-2026-10-03.md`. This page covers every finding not marked
"live" there: H2, H3/H4, H5-H8, the sixteen Medium items, the twenty-seven Low and Info items, the review items
R01-R05h and the twelve items fixed in v0.9.5 (V95-01..12): 74 in all. C1, C2 and H1 were reproduced live by the
audit itself.

## Method

- **Tests**: the Go test functions that each cited fix commit added or changed, confirmed present at `93bfedb`
  with `gograph node` (or, for `//go:build integration` files, by reading the file). They run in
  `make verify-parallel` (unit and integration legs) at this page's commit; see the commit that adds it.
- **Test book**: PASS rows of the workspace's `TESTBOOK-RUN-A`, `-V6` and `-V7-2026-10-08.csv` (and `-B` where it is
  the only PASS), with the version the row states. RUN-A holds 104 rows re-run on v0.9.10 (tag `v0.9.10`,
  `161ff3e`), RUN-V6 45 and RUN-V7 82; other rows state v0.9.9 or no version. "(related: ...)" marks a row that
  exercises nearby behaviour, not the exact fix.
- **Gap**: a finding with neither a test nor a test-book row. Section "Checks for the gaps" closes each one.
