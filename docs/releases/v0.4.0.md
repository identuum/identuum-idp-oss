# identuum-idp-oss v0.4.0 — release notes

Proposed tag: `v0.4.0` on `main`. **The owner pushes and publishes; nothing
in the repository performs either.** A local annotated `v0.4.0` tag exists so
the publish workflow's canonical binary-vs-tag gate has its input; pushing it
is an owner step.

## Theme: the public API is frozen

`pkg/` now holds exactly the six packages the commercial edition imports —
`features`, `licenseprovider`, `oidc`, `pkce`, `totp`, `webauthn` — and
nothing else, and a gate keeps it so. Decision P-061 measured the public API
as "what identuum-idp-ce imports"; the three `pkg/` directories nobody
outside this repository imported — `migrations`, `runtime`, `server` — moved
under `internal/pkg/` in `d1b9830`, and `api-surface` (`958a7d7`) fails
`make verify` and `make ci-verify` the moment a directory under `pkg/` is
missing or extra, naming it. A directory under `pkg/` is a contract for
free; moving one back under `internal/` later is a breaking change while
the reverse is not, so the freeze comes before the next feature work, not
after it.

Since `v0.3.7` (measured `v0.3.7..v0.4.0`, see the CHANGELOG for the
counts), in the order an integrator meets them:

- **Import paths.** `github.com/identuum/identuum-idp-oss/pkg/migrations`,
  `…/pkg/runtime` and `…/pkg/server` are gone; the packages live at
  `…/internal/pkg/migrations`, `…/internal/pkg/runtime` and
  `…/internal/pkg/server`, importable only from inside this module.
  Package names, exported identifiers and behaviour are unchanged. Measured
  before the move: no module outside this repository imported any of the
  three (identuum-idp-ce's full dependency closure names the six public
  packages and nothing else under `pkg/`), so no known integrator breaks;
  an unknown one would fail to compile, which is the honest signal.
- **The gate.** `make api-surface` — in `verify` (32 targets) and
  `ci-verify` (25) — enumerates the six in the recipe, cites P-061, and
  names every EXTRA or MISSING directory; it needs no sibling checkout and
  no network. Red-proved with an untracked `pkg/decoy/` and with `pkg/totp`
  moved aside, then green.
- **Nothing else.** No migration, no dependency, no endpoint, no toolchain
  change: Go 1.27.1, migrations `0001`–`0039`, the same dependency set as
  `v0.3.7`.
