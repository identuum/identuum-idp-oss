# identuum-idp-oss v0.3.3 — release notes

Proposed tag: `v0.3.3` on `main`. **The owner tags and pushes; nothing in the
repository performs either.**

## This is the first public release of the project

The repository is public, but it is not currently open source: no license
to use, copy, modify, distribute, sublicense, or create derivative works is
granted. It is published for viewing and evaluation only. External
contributions are not accepted. See [`LICENSE`](../../LICENSE) for the
exact terms and [`README.md`](../../README.md)'s Project Status section
for the summary.

This is a pre-company/public-preview posture, not a permanent one: a future
open-source release under a separate license may follow the project's legal
and organizational setup, at which point this notice will say so explicitly.
Until then, all rights remain reserved.

## No code or protocol behavior changes

Every change in this release is documentation, license text, or repository
metadata. No handler, migration, route, or response shape changed. The
binary version is **not** bumped by this release: no `ldflags` stamp, no
version-string commit.

## Changes

- **`LICENSE`** states the All-Rights-Reserved, view/evaluation-only terms
  (`SPDX-License-Identifier: LicenseRef-AllRightsReserved`) and that a
  future open-source release is possible but not yet published.
- **`NOTICE`** keeps the third-party-attribution paragraph — that paragraph
  is an obligation to this module's own Apache-licensed Go dependencies
  (declared in `go.mod`/`go.sum`), not a statement about this repository's
  own license.
- **`README.md`** carries a `## Project Status` section (published for
  viewing/evaluation only; not open source; no external contributions;
  current license named explicitly).
- **`SECURITY.md`**, **`.github/pull_request_template.md`**,
  **`.github/ISSUE_TEMPLATE/feature_request.md`**,
  **`docs/GETTING_STARTED.md`**, **`docs/PUBLICATION_CHECKLIST.md`**,
  **`deployment/README.md`** updated to match the current posture.
- **`CONTRIBUTING.md` deleted** — external contributions are not accepted,
  so a contributor guide describing how to submit one is not appropriate to
  keep.
- Go source comments naming the OSS/CE architecture boundary use neutral
  terminology already established elsewhere in the same files (`OSS`,
  `OSS-side`, `Starter-tier`) rather than a license-sounding name for that
  internal boundary concept.
- **`openapi.yaml`** (and its generator) no longer names a license in the
  generated API description.
- **`.gitignore`** gained `go.work`/`go.work.sum`, `__debug_bin*`, and
  `tls_certs/` — local development artifacts this repository's tooling can
  produce.
- **`CHANGELOG.md`** begins at this release.

## Compatibility
