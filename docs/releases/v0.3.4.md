# identuum-idp-oss v0.3.4 — release notes

Proposed tag: `v0.3.4` on `main`. **The owner pushes and publishes; nothing
in the repository performs either.** A local annotated `v0.3.4` tag exists
so the publish workflow's canonical binary-vs-tag gate has its input; the
push of that tag is an owner step.

## Theme: the appliance explains and repairs itself

Every customer-facing lifecycle operation is now one copy-paste command
against a plain docker/compose install, and the failure states that used to
look like a silent brick now name themselves.

## Highlights

- **`doctor`** — read-only diagnosis with named states (`version`, `db`,
  `at-rest-key` source, `setup`, `signing-key-seal`). Exit `0` healthy;
  non-zero names each failing state. Never prints DSNs or key material.
- **`factory-reset`** — guarded return to factory state (schema wipe +
  re-migrate → `setup_required`). Refused without the exact
  `--i-understand-this-destroys-all-data` flag, before any database
  contact.
- **Signing-key seal is loud** — undecryptable active signing keys put the
  process into NOT-SERVING: `/health` answers `503` with a named
  `signing-key-seal` fault; `doctor` names the same state from the CLI.
- **The wizard cannot eat credentials** — completing setup over an
  existing site_admin adopts and resets that account, the completion
  screen reports the pinned `site_admin@system.local` login, and
  migration 0031 makes the database itself refuse a setup-complete state
  without a live site_admin.
- **`GET /api/v1/health/details`** (site_admin) — runtime health with
  honest absence: fields OSS cannot measure are omitted, never zero-faked.
- **Admin state on the organizations surface** — `is_claimed` /
  `can_assign_admin` from live counts, with absence (not `false`) on any
  wiring gap.
- **One-command operations** — `docs/OPERATOR-GUIDE.md` walks doctor,
  setup-code re-display, break-glass recovery, bootstrap, migrate,
  factory-reset, and version as single `docker exec` commands; every
  one-shot subcommand resolves its database from the container's own
  environment.
