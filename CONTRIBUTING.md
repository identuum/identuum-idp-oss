# Contributing

Thank you for your interest in identuum-idp-oss.

## Pull requests

We do not accept pull requests or patches yet (see [LICENSE](LICENSE)).
If that changes, this file will say how to contribute. There is no CLA or
DCO to sign today.

## How you can help now

- Report bugs and request features through the
  [issue forms](https://github.com/identuum/identuum-idp-oss/issues/new/choose).
- Never report a security issue in public. Follow [SECURITY.md](SECURITY.md).

## A good bug report

Give us:

- the version: the output of `identuum-idp version`, or the version on the
  console's Platform status page;
- how you installed it: Docker Compose, the binary, or from source;
- your PostgreSQL version;
- the steps that show the problem;
- what you expected, and what happened;
- logs, with secrets removed (tokens, cookies, passwords, database URLs,
  TOTP secrets, recovery codes and key material).

## Feature requests

This repository is the open edition of Identuum. Ask for features that fit
it. Some features belong to the separate commercial edition; we may close a
request for one of those here.

## Response times

We answer issues on a best-effort basis. We do not promise a response time.
